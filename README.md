# Yahya Yusuf - Student Portfolio and Academic Management Website

COS 106 term project. Multi-page site built with HTML, CSS and JavaScript.

## Pages
- `index.html` - homepage (name, photograph, welcome message, navigation, brief biography)
- `about.html` - education, career aspirations, technical skills, table, lists, hobbies
- `projects.html` - three projects with images, descriptions, links and a video
- `planner.html` - interactive task manager (add, complete, delete, filter)
- `contact.html` - contact form with JavaScript validation

## Folders
- `css/style.css` - external stylesheet (responsive, flexbox and grid, transitions and animations)
- `js/` - `main.js` (shared), `planner.js`, `contact.js`
- `images/`, `media/` - pictures and video

## Before you submit
1. Replace `images/profile.svg` with your photograph (update the `src` in `index.html` and `about.html`, e.g. `images/profile.jpg`).
2. Replace `media/walkthrough.mp4` with your own video, or delete the section.
3. Replace the `href="#"` demo links on the projects page with real URLs.

## Host on GitHub Pages
1. Create a GitHub repository and upload everything in this folder (so `index.html` is at the root).
2. Repository Settings, then Pages. Under Branch choose `main` and `/ (root)`, then Save.
3. After a minute your site is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`. Submit that link and the repository link.
